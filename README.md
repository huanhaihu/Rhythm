## 下载安装

### 方式一：下载 DMG（推荐）

1. 前往 [Releases 页面](https://github.com/huanhaihu/Rhythm/releases) 下载最新的 `Rhythm.dmg`
2. 打开 DMG，将 **Rhythm.app** 拖入右侧 **Applications** 文件夹
3. 在 Launchpad 或 Spotlight 中搜索 "Rhythm" 启动

> **首次打开提示**：macOS 可能显示"无法验证开发者"，请前往
> **系统设置 → 隐私与安全性 → 仍然打开** 允许运行。

### 方式二：从源码构建

```bash
git clone https://github.com/huanhaihu/Rhythm.git
cd Rhythm
xcodebuild -project Rhythm.xcodeproj -scheme Rhythm \
  -configuration Release -derivedDataPath build build
cp -R build/Build/Products/Release/Rhythm.app /Applications/
open -a Rhythm
```

**环境要求**：macOS 13.0 (Ventura) +，Xcode 16+

## 功能特性

| 功能 | 说明 |
|------|------|
| 专注计时 | 自定义工作时长，到时自动提醒休息 |
| 全屏休息界面 | 半透明磨砂覆盖层，圆形倒计时 + 随机休息建议 |
| 随机微休息 | 每隔 4–5 分钟播放提示音，提醒 10 秒短暂休息，不打断工作流 |
| 菜单栏常驻 | 实时倒计时显示在菜单栏右上角，随时可见 |
| 内联设置 | 直接在菜单弹窗中调整时长，无需打开单独窗口 |
| 数据记录 | 自动记录每次休息（完整 / 跳过 / 立即 / 微休息） |
| 开机启动 | 一键设置登录时自动启动 |
| 锁屏自动暂停 | 锁屏或开屏保时自动停止，保护计时准确性 |
| 单实例保护 | 重复启动时弹窗提示，防止进程死锁 |

## 使用说明

### 启动

打开 Rhythm 后，图标出现在屏幕**右上角菜单栏**。点击图标打开控制面板，点击底部 **「开始专注」** 开始计时。

> 若菜单栏图标被遮挡，按住 **⌘ Command** 将其他图标拖开腾出空间。

### 底部按钮

| 按钮 | 何时可用 | 说明 |
|------|----------|------|
| **开始专注** | 已暂停时（蓝色高亮） | 启动工作计时器 |
| **暂停** | 运行中时 | 停止所有计时 |
| **立即休息** | 专注中时 | 立刻触发一次完整休息 |
| **重置计时** | 运行中时 | 用当前设置重新开始计时 |
| **跳过休息** | 休息进行中时 | 跳过本次休息，回到专注 |
| **退出** | 随时 | 完全退出 Rhythm |

---

### 休息界面

工作时间结束后，屏幕弹出**全屏休息界面**：
- 圆形进度环实时显示剩余休息时间
- 随机展示休息建议（冥想、走动、伸展、眼部放松等共 10 条）
- 点击 **「跳过，继续工作」** 或按 **ESC** 可跳过

### 微休息

工作期间每隔约 4–5 分钟（随机），Rhythm 会：
1. 播放一声提示音（微休息开始）
2. 菜单栏显示 `微休 10s` 倒计时
3. 10 秒后再播放一声（结束）

## 常见问题

**Q：打开后没有自动开始计时？**
A：设计如此，请手动点击「开始专注」。

**Q：菜单栏看不到图标？**
A：按住 ⌘ 将其他图标拖走，或检查是否被隐藏图标工具（如 Bartender）折叠。

**Q：出现两个 Rhythm 进程怎么办？**
A：新版已内置防重复启动保护。若遇旧版残留：`pkill -9 -x Rhythm`

**Q：休息弹窗如何关闭？**
A：点击「跳过，继续工作」或按 **ESC**。
