# Rhythm 使用说明

Rhythm 是一款 macOS 菜单栏应用，帮助你在工作中保持健康的休息节奏。

---

## 安装与启动

1. 将 `Rhythm.app` 拖入 `/Applications` 文件夹
2. 双击打开，或在 Spotlight 中搜索 "Rhythm" 启动
3. 启动后图标出现在**屏幕右上角菜单栏**
4. 如果已有一个 Rhythm 在运行，再次打开时会弹出提示并自动退出，无需担心重复进程

> 如果菜单栏图标被其他图标遮挡，按住 Command 键将其他图标拖走即可腾出空间。

---

## 基本使用

### 开始计时
点击菜单栏图标 → **开始计时**

计时器启动后，菜单栏会显示距下次休息的倒计时，例如 `24:59`。

### 休息提醒
工作时长到达后，屏幕会弹出**全屏休息界面**：
- 圆形倒计时显示剩余休息时间
- 随机显示一条休息建议（冥想、伸展、眼部放松等）
- 点击 **"跳过，继续工作"** 或按 **ESC** 可跳过本次休息

### 微休息
每隔约 4–5 分钟（随机），Rhythm 会自动触发一次 **10 秒微休息**：
- 不弹出全屏界面，只播放一声提示音
- 菜单栏显示 `微休 10s` 倒计时
- 微休息结束时再播放一声提示音
- 可在菜单中点击 **"跳过微休息"** 手动跳过

## 菜单功能

| 按钮 | 说明 |
|------|------|
| 开始计时 | 启动工作计时器 |
| 立即休息 | 立刻触发一次完整休息 |
| 一键重置 | 清零计时，以当前设置重新开始 |
| 跳过微休息 | 仅在微休息进行中显示，跳过当前微休息 |
| 暂停计时 | 暂停所有计时，数据清零 |
| 打开设置 | 打开设置与数据统计窗口 |
| 退出 Rhythm | 完全退出应用 |

## 设置项说明

打开 **"打开设置"** 进入设置界面。

### 工作与休息
| 设置 | 默认值 | 说明 |
|------|--------|------|
| 工作时长 | 25 分钟 | 每次工作持续时间 |
| 休息时长 | 5 分钟 | 每次完整休息时间 |

### 微休息
| 设置 | 默认值 | 说明 |
|------|--------|------|
| 启用微休息 | 开启 | 是否启用随机短暂提醒 |
| 微休息时长 | 10 秒 | 每次微休息持续秒数 |
| 最短间隔 | 240 秒（4 分钟） | 两次微休息最短间隔 |
| 最长间隔 | 300 秒（5 分钟） | 两次微休息最长间隔 |

### 声音
- **休息提示音**：工作时长到达时播放（默认 Glass）
- **微休息提示音**：微休息开始和结束时播放（默认 Ping）
- 支持上传自定义音频文件（.mp3 / .wav / .aiff）

### 其他
- **自动启动计时**：打开 Rhythm 后自动开始工作计时

## 数据统计

切换到 **"统计"** 标签查看今日数据：

| 指标 | 说明 |
|------|------|
| 完整周期 | 自然完成的工作→休息完整循环次数 |
| 立即休息 | 手动点击"立即休息"的次数 |
| 微休息 | 完成的微休息次数 |
| 跳过 | 跳过休息的次数 |
| 重置 | 点击"一键重置"的次数 |
| 总休息时长 | 当天实际休息的总秒数 |

下方列表显示每条休息记录的详细信息（时间、类型、时长、是否跳过）。

## 锁屏行为

锁屏或开启屏保时，Rhythm 会**自动暂停计时**，解锁后需手动点击"开始计时"重新启动。

## 常见问题

**Q：菜单栏图标找不到了？**
A：可能被其他图标遮挡。按住 Command 键将其他图标向右拖动腾出空间。

**Q：重复启动了两个 Rhythm 怎么办？**
A：新版本已内置防重复启动保护，会弹出提示并自动退出多余实例。如遇旧版本卡死，在终端执行 `pkill -9 -x Rhythm` 强制终止所有进程，再重新打开即可。

**Q：休息界面弹出后我想继续工作？**
A：点击界面上的 **"跳过，继续工作"** 按钮，或直接按键盘 **ESC** 键。

**Q：如何完全退出 Rhythm？**
A：点击菜单栏图标 → **退出 Rhythm**。
